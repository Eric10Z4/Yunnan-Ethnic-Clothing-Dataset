## 一、 快速开始指南

1. **一键启动**：
   直接双击文件夹内的 **`双击打开评审系统.bat`**（或直接双击 **`index.html`**），即可在任意浏览器中秒开（纯离线运行，零安装依赖）。
2. **极速盲操打标（单手即可完成）**：
   - 看到符合标准的图片：直接按键盘 **`J`** 或 **`空格`** 或 **`Enter`**（标记为【合格】并毫秒级自动跳入下一张）；
   - 发现有瑕疵的图片：直接按数字键 **`1` ~ `7`** 标记具体原因（系统会自动记录病因并跳入下一张）：
     - 按 **`1`**：🎨 插画 / 漫画 / 3D渲染 / AI绘图
     - 按 **`2`**：👤 纯脸大特写 / 自拍照 / 缺乏服饰
     - 按 **`3`**：🧵 方形布料 / 扎染面料 / 桌布挂毯 / 非成衣
     - 按 **`4`**：👕 现代日常便装 / T恤牛仔卫衣 / 非少数民族服饰
     - 按 **`5`**：👥 多人合影 / 群舞合照（严禁2人及以上）
     - 按 **`6`**：✂️ 抠图破损 / 严重黑灰脏斑 / 残缺断肢
     - 按 **`7`**：❓ 其他原因（支持弹出输入框填写具体原因）
   - 翻页修改：按键盘 **`←` / `→`** 可随时返回重审。
3. **导出交付清单**：
   全部审完后，点击右上角绿色的 **【💾 导出第二轮复审清单】**，浏览器会自动下载一份 CSV 清单：
   `民族服饰数据集第二轮复审清单_YYYY-MM-DD.csv`，将此文件发送给负责人**邹弘辉**即可！

## 二、 核心评审标准与判断原则

### ✅ 【合格 (PASS)】必备准则（同时满足）：
1. **真实摄影实体照片**：必须是真实相机拍摄的照片，绝对不能是手绘插画、动漫或AI渲染。
2. **服装是绝对主体**：画面展示了充分的民族服装面积（全身或大半身），能清晰看到衣服形制款式，绝不能是只有一张脸的大头照。
3. **单主体展示**：画面中只有【一位模特穿着】或【一件成衣单品展示】。
4. **真正少数民族服饰**：具有云南少数民族鲜明传统形制特征（如百褶裙、蜡染长衫、银饰冠帽、筒裙、刺绣坎肩），而非现代便服。
5. **背景纯白干净**：512×512 纯白背景，无大块复杂背景残渣。

- **永不丢进度**：每一次点击均通过浏览器 `LocalStorage` 实时保存，电脑关机重启后重新打开依然保留所有历史记录，并可通过右上角 **【🔍 跳至下一张待审】** 快速续跑！
