📋 人工评审参考准则

✅ 【合格 (PASS)】必备准则： 1. 单主体：单人穿着、单件服装、成套展品或独立服饰配件。
2. 按类别核对：服装应展示主体；独立鞋帽、背饰等不因不是整套衣服而自动否决。
3. 真实实拍：真实相机拍摄，非手绘插画/AI虚构。
4. 白底干净：背景纯白无大块污斑与残渣。民族归属争议需核对公开来源，不凭外观确认。
❌ 【不合格】细分归因： • 插画/手绘/3D：画出来的、二次元、AI绘画。
• 纯脸特写/缺服饰：只有人脸大头照，无核心服饰。
• 方形布料/桌布：桌布面料、布样布条、非成衣。
• 现代便装/非民族：T恤牛仔裤卫衣、普通便服。
• 多人合影：画面出现2人及以上合照。
• 抠图破损/严重污斑：断头断手、严重黑灰杂色。
• 其他原因：非以上原因的其它瑕疵。
