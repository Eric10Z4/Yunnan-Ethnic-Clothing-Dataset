📋 终审考核核心准则

✅ 【合格 (PASS)】必备准则： 1. 单主体：画面只有1位模特或1件衣服挂展。
2. 衣服为主：有充分的服装面积展示（全身/大半身）。
3. 真实实拍：真实相机拍摄，非绘画插画。
4. 白底干净：背景纯白无污斑残渣。
❌ 【不合格】针对性原因细分： • 插画/手绘/3D：画出来的、动漫、AI绘画。
• 纯脸特写/缺服饰：只有人脸大头照，无衣服。
• 方形布料/桌布：桌布面料、布样、非成衣。
• 现代便装/非民族：T恤牛仔裤卫衣、普通便服。
• 多人合影：画面出现2人及以上合照。
• 抠图破损/污斑：断头断手、严重黑灰杂色。
• 其他原因：非以上原因的其它瑕疵。
