# 云南民族服饰图像数据集 · 人工多维终审操作指南 (v2)

欢迎使用《计算机视觉》期中大作业——民族服饰图像数据集**人工多维终审系统 (v2)**！

本版本专门针对前期审查中暴露的“插画、纯脸特写、方形布料、现代便服”等隐蔽问题进行了全方位升级，支持**一键多维归因标记**与**全键盘极速盲操**。

---

## 一、 快速开始指南

1. **一键启动**：
   直接双击文件夹内的 **`双击打开评审系统.bat`**（或直接双击 **`index.html`**），即可在任意浏览器中秒开（纯离线运行，零软件依赖）。
2. **极速盲操打标（单手即可完成）**：
   - 看到符合标准的图片：直接按键盘 **`J`** 或 **`空格`** 或 **`Enter`**（标记为【合格】并毫秒级跳入下一张）；
   - 发现有瑕疵的图片：直接按数字键 **`1` ~ `7`** 标记具体原因（系统会自动记录病因并跳入下一张）：
     - 按 **`1`**：🎨 插画 / 漫画 / 3D渲染 / AI绘图
     - 按 **`2`**：👤 纯脸大特写 / 自拍照 / 缺乏服饰
     - 按 **`3`**：🧵 方形布料 / 扎染面料 / 桌布挂毯 / 非成衣
     - 按 **`4`**：👕 现代日常便装 / T恤牛仔卫衣 / 非少数民族服饰
     - 按 **`5`**：👥 多人合影 / 群舞合照（严禁2人及以上）
     - 按 **`6`**：✂️ 抠图破损 / 严重黑灰脏斑 / 残缺断肢
     - 按 **`7`**：❓ 其他原因（支持弹出输入框填写具体原因）
   - 翻页修改：按键盘 **`←` / `→`** 可随时返回重审。
3. **导出交付清单**：
   全部审完后，点击右上角绿色的 **【💾 导出终审结果清单】**，浏览器会自动下载一份 CSV 清单：
   `民族服饰数据集人工终审结果清单_YYYY-MM-DD.csv`，将此文件发送给团队负责人**邹弘辉**即可！

## 二、 核心评审标准与判断原则

### ✅ 【合格 (PASS)】必备准则（同时满足）：
1. **真实摄影实体照片**：必须是真实相机拍摄的照片，绝对不能是手绘插画、动漫或AI渲染。
2. **服装是绝对主体**：画面展示了充分的民族服装面积（全身或大半身），能清晰看到衣服形制款式，绝不能是只有一张脸的大头照。
3. **单主体展示**：画面中只有【一位模特穿着】或【一件成衣单品展示】。
4. **真正少数民族服饰**：具有云南少数民族鲜明传统形制特征（如百褶裙、蜡染长衫、银饰冠帽、筒裙、刺绣坎肩），而非现代便服。
5. **背景纯白干净**：512×512 纯白背景，无大块复杂背景残渣。

---

### ❌ 【不合格 (FAIL)】七大细分选项速查：
| 按键 | 归因分类 | 典型特征与反例 |
| :---: | :--- | :--- |
| **1** | **插画/手绘/3D/AI生成** | 电脑画出来的矢量图、漫画二次元、国画绘本、3D人偶渲染、AI生成的虚拟画像。 |
| **2** | **纯脸特写/缺乏服饰** | 画面只有一张大脸、化妆大头照、自拍照，脖子以下服饰严重缺失或只露衣领。 |
| **3** | **方形布料/面料桌布** | 铺在桌上的扎染方形布块、刺绣面料样卡、挂毯、鞋垫、纯布匹展示，不是穿的衣服。 |
| **4** | **现代便装/非少数民族** | 穿普通T恤、连帽卫衣、牛仔裤、现代时装在景区随手拍的游客照，无民族特征。 |
| **5** | **多人合影/群演照片** | 画面出现 2 人及以上（无论抠图是否成功，严禁合照！）。 |
| **6** | **抠图破损/严重污斑** | 人物断头断肢、服饰被切掉大半、四周带有大片黑色/灰色烟雾残余。 |
| **7** | **其他原因** | 其它非上述归因的特殊瑕疵（点击可填写自定义理由）。 |

## 三、 温馨特性与进度自愈
- **永不丢进度**：每一次点击均通过浏览器 `LocalStorage` 毫秒级静默保存，哪怕电脑关机重启，重新打开依然保留所有历史记录，并可通过右上角 **【🔍 跳至下一张待审】** 快速续跑！
