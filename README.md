# Yunnan Ethnic Clothing Dataset Construction | 云南民族服饰图像数据集构建

本项目为**云南大学软件学院 2026 春季学期《计算机视觉》课程期中大作业**（指导教师：黄珊珊）。

聚焦中国 56 个经确认民族中的**云南特色世居少数民族服饰**，构建一个**来源可追溯、标注规范、几何合规、质量合格、直接面向生成式视觉与多模态研究**的科研级图像数据集。

> **仓库存储说明**：本仓库遵循科研数据分发最佳实践与轻量化原则，**不直接上传数以万计的原始图片二进制文件**（通过 `.gitignore` 过滤），而是完整提供全量 **6,259 样本的来源 URL、发布机构、采样时间戳、6级清洗剔除台账 (exclusion_log.csv)、清洗后元数据表 (cleaned_metadata.csv) 及全套自动化采集与构建代码**，保证 100% 来源可查、可复现下载。

## 一、项目背景与核心考核指标

本次期中作业聚焦数据集工程全流程，**明确不要求训练分类或生成模型**，核心考核数据集质量与规范性（100分制）：
1. **真实可追溯**：类别严格依据可信文献、博物馆典藏或原始发布页面，严禁凭外观主观推测。
2. **纯白底与单主体**：RGB 严格为 `(255, 255, 255)`，仅包含单件服饰或单人穿着，杜绝合影拼图。
3. **严格几何约束**：
   - 居中度：主体中心横纵偏差 $\le 10\%$（$\le 51.2$ px）。
   - 主体尺度：主体外接框较长边 $\ge 60\%$（$\ge 307.2$ px）。
   - 画布尺寸：等比例缩放并白色补边至 $512 \times 512$ 像素。
4. **高质量图文对齐**：细粒度结构化 JSON 属性 + 规范英文描述，未知属性标 `unknown`。

## 二、全流程工业级流水线架构

本项目构建了包含**闭环双重质检机制**的端到端自动化数据工程流水线：

```
[原始多源采集] (博物馆典藏 + 必应溯源)
       │
       ▼ (6,259 张原始图库 + raw_metadata.csv)
[六级级联清洗漏斗]
  ├── 1. 文件流完整性解码校验 (Integrity Check)
  ├── 2. 几何分辨率 (min>=220px) 与异常长宽比过滤 (AR<=3.0)
  ├── 3. 信息熵纯色过滤 (std(L)>=15.0)
  ├── 4. 标准化参考尺度拉普拉斯清晰度计算 (variance>=45.0)
  ├── 5. 像素级 MD5 精准去重 (Exact Dedup)
  └── 6. 32x32 DCT 感知哈希近重复去重 (pHash Hamming<=5)
       │
       ▼ (5,424 张高质去重库 + exclusion_log.csv + cleaned_metadata.csv)
[阶段三：主体抠图与几何标准化]
  ├── Rembg / SAM 智能主体前景提取与 RGB(255,255,255) 纯白底合成
  ├── 75% 尺度居中缩放与 512x512 纯白补边
  ├── ★ 视觉大模型 (VLM) 自动化抠图验收 (过滤边缘毛刺与残肢)
  └── ★ 人工双重核验闭环
       │
       ▼
[阶段四：多模态大模型细粒度结构化标注]
  ├── 提示词工程驱动 VLM 提取 top, bottom, headwear 结构化属性
  ├── 材质属性严格未知打标 (unknown 杜绝幻觉)
  ├── 词表归一化 (Lexicon Normalization) 强制拼写全库一致
  └── 导出 captions.jsonl (图像生成配对集)
       │
       ▼
[阶段五：质量审计、70/15/15分层切分与交付]
```

## 三、当前建设进展与数据资产台账

### 1. 阶段一：高通量多源采集
已完成云南 10 大代表性世居少数民族服饰全量采集，共计 **6,259 张图片 (1.8 GB)**，元数据已记录至 `dataset/raw/raw_metadata.csv`。

### 2. 阶段二：六级漏斗清洗与感知去重
全量 6,259 张图片经 `code/02_clean_and_dedup.py` 自动化过筛：
- **有效合格保留**：**5,424 张**（留存率：`86.66%`）
- **拦截剔除总数**：**835 张**（逐样本原因详见 `dataset/cleaned/exclusion_log.csv`）
  - 感知哈希近重复 (pHash): 461 张
  - 像素级完全重复 (MD5): 281 张
  - 分辨率过小 / 极端比例: 67 张
  - 文件损坏 / 解码异常: 18 张
  - 模糊 / 虚焦: 7 张
  - 单色占位图: 1 张

## 五、快速复现指南

### 环境准备
```bash
# 克隆代码仓库
git clone https://github.com/Eric10Z4/Yunnan-Ethnic-Clothing-Dataset.git
cd Yunnan-Ethnic-Clothing-Dataset

# 安装 Python 依赖
pip install -r code/requirements.txt
```

### 一键重新清洗与去重
```bash
python code/02_clean_and_dedup.py
```
