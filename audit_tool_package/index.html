📋 评审考核核心红线

请仔细比对中央图片，满足以下【合格标准】方可点击“合格”，有一项严重违反则判定“不合格”。

✅ 【合格】必备标准（PASS） 1. 单主体展示：画面必须只有【一位模特穿着】或【一件服饰单品展示】。
2. 主体完整可辨：上衣、下装（或裙装）、特色头饰清晰可见，无严重残破截断。
3. 背景纯白干净：背景为纯白，四周无大块复杂原图背景块、无明显污斑阴影。
❌ 【不合格】一票否决项（FAIL） 1. 多人合影：画面中出现 2 人及以上（无论抠图是否成功，严禁多人合影！）。
2. 严重残破/断头断肢：人物身体严重缺失、只剩半个肩膀或服饰被切掉一半。
3. 非服饰工艺品：仅展示桌布、围巾角、挂画，并非衣服本身。
4. 抠图严重失真：大面积烟雾污块、严重的锯齿撕裂。
